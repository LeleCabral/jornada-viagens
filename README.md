<h2>✈️ Jornada Viagens - Landing Page Responsiva</h2>

📌 Sobre o Projeto:
Este é um projeto de uma agência de viagens moderna, focado em visual storytelling e experiência do usuário (UX).
O site foi desenvolvido para ser totalmente responsivo, adaptando-se de telas mobile até monitores ultra-wide (1920px).

🚀 Tecnologias Utilizadas
HTML5 (Semântico)
CSS3 (Flexbox, Grid)
Git/GitHub 
Mobile First Methodology

Como rodar o projetoClone o repositório:

Bashgit clone https://github.com/seu-usuario/jornada-viagens.git

Abra o arquivo index.html no seu navegador.
